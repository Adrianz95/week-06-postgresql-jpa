# Sistema de reservas de salas

Proyecto formativo para aprender PostgreSQL y JPA
mediante el desarrollo de una aplicación de reservas.

## Tecnologías

- Java
- Spring Boot
- PostgreSQL
- JPA / Hibernate

## Base de datos

La primera iteración contiene las tablas:

- users
- rooms
- reservations
